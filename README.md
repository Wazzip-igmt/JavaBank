## 📌 Sobre o projeto

O **Sistema Bancário** simula operações básicas de um banco através de um menu interativo no terminal.

O projeto foi desenvolvido **manualmente em Java**, sem frameworks, com foco em colocar em prática os conceitos aprendidos durante meus estudos.

A ideia foi transformar conceitos básicos de programação em uma aplicação funcional.

---

## 💰 Funcionalidades

| Função           | Descrição                          |
| ---------------- | ---------------------------------- |
| 🔐 Login         | Acesso protegido por senha         |
| 💵 Saldo         | Consulta do saldo disponível       |
| 📥 Depósito      | Adiciona dinheiro à conta          |
| 📤 Saque         | Realiza saques com validação       |
| 📋 Extrato       | Consulta as operações realizadas   |
| 🔑 Alterar senha | Permite modificar a senha da conta |
| 🔢 Tentativas    | Controle de tentativas de login    |
| 🚪 Sair          | Encerra o sistema                  |

## 🖥️ Funcionamento

O sistema apresenta um menu no terminal:

```text
╔══════════════════════════╗
║      🏦 BANCO JAVA       ║
╠══════════════════════════╣
║ 1 - 💰 Ver saldo         ║
║ 2 - 📥 Depositar         ║
║ 3 - 📤 Sacar             ║
║ 4 - 📋 Extrato           ║
║ 5 - 🔑 Alterar senha     ║
║ 6 - 🚪 Sair              ║
╚══════════════════════════╝
```

O usuário escolhe uma operação e o sistema executa as regras correspondentes.
